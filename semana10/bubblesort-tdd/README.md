# Bubble Sort — TDD

Ordena o vetor de inteiros em ordem crescente com Bubble Sort, preservando valores repetidos. Os testes originais foram mantidos e foram acrescentados casos para vetor vazio, unitário, inverso e valores negativos.

Execute `mvn clean verify`. O relatório de cobertura fica em `target/site/jacoco/index.html`. Consulte `REQUISITOS.md` para o enunciado.
