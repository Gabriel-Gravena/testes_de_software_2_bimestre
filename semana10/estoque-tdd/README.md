# Estoque — TDD

O produto começa com estoque zero, acumula entradas e permite retiradas até o estoque disponível. Entradas e retiradas não positivas e retiradas acima do estoque são ignoradas. Os testes originais foram preservados e complementados com casos de limite.

Execute `mvn clean verify`. O relatório de cobertura fica em `target/site/jacoco/index.html`. Consulte `requisitos_estoque_tdd.md` para o enunciado.
